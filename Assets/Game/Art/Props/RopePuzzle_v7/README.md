## 新增素材

- 绕绳钩：过去空钩、收绳参考、现在断裂锈坏。
- 绳结：系住、解开后的连续松绳。
- 绳索：可抓取的结头绳尾、连续绘制用的长条纹理。
- 成年树支点：裸枝杈、搭绳接触参考。
- 遮挡层：现在粗树干的前景树皮。
- 近景底图：过去小树旁解结场景，绳结单独叠加。

## 分层与接入

过去：小树/近景底图 → 背侧绳段 → 树干遮挡 → 前侧绳结与可抓绳尾。
现在：成年树与枝杈 → 连续绳路 → 必要树皮前景。未解开的旧结应被粗树干真实遮住，不在遮挡上方偷偷亮交互点。

架子、空绕绳钩保留为稳定物件，拖动时用长绳纹理与绳尾绘制连续绳路。带绳枝杈和收绳钩整图主要说明接触关系，避免直接交换整张图导致树枝和木座跳动。

两张绳结图是状态素材，不代表已经有了流畅的解结动画。两个年代的钩座需以螺栓为配准点。绳纹理的UV、尺度和重复接缝需接入时确定。

本包补齐v7当前静态美术清单；机关能否正确受力、过关是否好玩，仍需下一步灰盒和接入确认。原有资产全部保留。
