## 切帧与接入

- 图片按从左到右、从上到下排序。**不要直接按等高网格切分**：生成图的部分行间距不均匀。
- `animation_manifest.json` 已记录每帧实际源图矩形：`rect_top_left` 为左上坐标的左右上下边界；`rect_unity_bottom_left` 为 Unity 使用的左下坐标 x/y/width/height。
- 可见区域采用 Alpha > 32 记录，透明像素保持原始数据，未对生产图片执行程序抠图或重绘。
- 导入时设 Sprite Multiple、Full Rect、Bilinear。以统一人物世界身高设置各图 PPU，并逐帧校准脚底 pivot，不能只增加播放 fps。
- 生成帧存在轻微外形和落脚位置变化，当前切帧坐标保证人物完整，**不等于已完成脚底与骨盆对齐**。行走循环相位仍需在接入时选帧、排序和调整时间；帧数达标不代表已验证无抖动。
- 跳跃应由真实运动状态选择起跳、空中、下落和落地分段；不要把12帧全部无条件定时播放，以免角色已落地仍播放腾空。
- 爬梯仅在实际移动时循环，停梯保持当前帧。拾取动作中的衣物与场景道具显隐要衔接，避免出现两份。
- 攀台图提供动作姿态，不会自动增加攀台能力；若使用，需按真实台面和手脚接触点调整根节点。
