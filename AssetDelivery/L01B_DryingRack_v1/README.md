# L01B 折叠晾晒架素材交付

包含7张机关透明PNG、1张自然桂花树候选、4条机关WAV和1条连续试听。人物拉绳动画已按用户要求取消，不交付、不接入。

打开 preview.html 看透明层与试听；contact_sheet.jpg 为静态总览。生成使用内置 imagegen，提示词保存在 Source/prompts.json；音效用已有仓库音频加工与本地合成制作，参数与来源见 manifest.json。所有游戏PNG保留生成Alpha，未覆盖原素材。

## 机关层与装配

- RackMount_1994：完好固定支座、滑轮、下铰链；RackMount_2024：缺滑轮、断绳、裂木与锈蚀。
- RackLeaf_1994：完整活动木架；以左端铰孔为旋转中心，从向下收起转到水平，顶缘为可站面。
- RackLeaf_2024：损坏残架，只作视觉，不应产生连通碰撞。
- RackBrace_1994：独立支撑臂，两端连接墙侧下固定点与木架下方支点；按装配尺寸旋转，不要把它固定成悬空斜条。
- RackLatch_Open / Closed：开合差分。轴心有生成偏差，必须按 manifest.json 中各自轴心配准，不能直接同原点换图。
- 绳索用 LineRenderer 绘制，连接架端绳眼与固定滑轮，另一段垂到操作点；不需要额外生成绳图。

manifest 中坐标从图像左上起算、归一化，为人工估测装配参考。Unity pivot 的Y从底部计算，使用 1-y；接入时仍需视检微调。PNG建议 Sprite 单图、保留Alpha、Filter Bilinear、关闭有损压缩；PPU按场景尺寸设置。

## 自然树候选与通路限制

用户否定旧版横向平台树，本包改用真实感较强的向上分叉桂花树。新树并非旧图的同轮廓替换，不承诺沿旧碰撞可走。

建议路线为：过去木梯 → 恒定平台 → 过去晾晒架 → 现在树的主干分叉/短粗枝 → 恒定窗台 → 出口。不要把人物送到细枝末端，也不要延续旧图横贯整棵树的水平通路。粗枝附近的可走碰撞、固定窗台高度、跳距与树图缩放必须一起调整，之后用真实角色验证。

## 接入尚未执行

本次只交付素材，没有修改关卡场景、碰撞、机关逻辑或打包游戏。尚需机关未升起/升起中/锁定状态、完成存档、年代切换安全校验、落稳后碰撞启用、E交互和H提示；并验证防绕解、暂停/读档和跌落恢复。

## 音效

- rope_pull：拉绳摩擦，一次下拉。
- raise_creak：木架与铰链升起。
- latch_lock：锁扣入位。
- broken_rattle：现在态损坏反馈。

四条均为48kHz双声道PCM24 WAV，不是语音或环境录音。当前为素材级波形/格式检查，最终音量与动作时序仍需游戏内试听。
