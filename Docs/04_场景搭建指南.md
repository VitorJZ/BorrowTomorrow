# 04 场景搭建指南

> 描述项目中**必须遵守**的场景结构约定。脚手架（`BorrowTomorrow → 一键搭建项目骨架`）生成的场景已符合本规范，可作为参照。

## 1. 排序层与物理层（已由脚手架配置）

### 1.1 排序层（策划 8.5，从后到前）

| 排序层 | 用途 |
| --- | --- |
| `Sky` | 远景天空 |
| `FarBuildings` | 远景建筑 |
| `EraBackground` | 双年代背景（受 Sprite Mask 控制） |
| `ConstantStructure` | 恒定结构（砖台、门槛、主梁） |
| `EraPlatform` | 年代平台 / 年代物体 |

规则：可通行平台不得被前景遮住；字幕区域避免覆盖必看机关；机关和角色不得使用不同视差系数。

## 2. Bootstrap 场景（系统根，策划 10.3）

```
SystemRoot                          ← DontDestroyOnLoad（Bootstrap 组件保证）
├─ Bootstrap / GameSession
├─ SaveService / CheckpointService
├─ AudioService / SfxLibrary
├─ NarrativeDirector / DialogueLibrary / DialoguePlayer
├─ InputRouter
└─ UICanvas（Canvas，Screen Space Overlay，参考分辨率 1920×1080）
   ├─ HudService
   ├─ SubtitlePanel / ObjectivePanel / InteractionPrompt
   ├─ BoundaryHandle（顶部把手，命中区 ≥44px）
   ├─ HintToast / EraBadge / FadeScreen
   ├─ PauseMenu / ResumeConfirmDialog
EventSystem
```

- 关卡场景**不**放置任何系统组件；重开关卡不会重复创建音频、输入与事件监听器。
- 面板内的 TMP 文本、按钮由美术/程序接入时在 Inspector 填充（字段留空时代码安全容错）。
- `GameSession.levelCatalog` 在此场景按通关顺序拖入全部 `LevelDefinition`。

## 3. 关卡场景结构（每关一个 .scene；L01 为双房间）

```
RoomRoot_<roomId>                   ← LevelRoot + TemporalObjectRegistry
│                                     + BoundaryController + LevelDirector + HintDirector
TemporalVisual
├─ PastMask（SpriteRenderer[VisibleInsideMask] + SpriteMask，1×1 白矩形）
└─ PresentMask（同上）
Main Camera                         ← 正交 5.4；CameraRig2D
Content
├─ Ground（layer Ground，BoxCollider2D，摩擦力>0 的 PhysicsMaterial2D）
├─ Spawn_<id>（SpawnPoint）
├─ Checkpoint_mid（BoxCollider2D isTrigger + CheckpointMarker）
├─ KillZone（底部，isTrigger + KillZone 组件）
├─ Temporal_<objectId>              ← TemporalObject
│  ├─ Past（SpriteRenderer + Collider2D）
│  └─ Present（SpriteRenderer + Collider2D）
└─ Exit_NextLevel（layer Interactable + ExitDoor）
```

要点：

1. **房间范围**：`LevelRoot` 的 `boundaryMin/Max` 决定边界把手可拖范围；`cameraBounds`（Rect）决定镜头边界。
2. **双年代背景**：`TemporalVisualController` 持有 `PastMask/PresentMask` 引用与 `roomLeft/roomRight`；背景 Sprite 全部设 `Mask Interaction = Visible Inside Mask` 并放 `EraBackground` 层。恒定层不受遮罩。
3. **出生点命名**：`Spawn_<spawnId>` 与 `LevelDefinition.spawnId` 一致；**检查点 marker 的 `checkpointId` 若与某出生点同名，恢复优先放该出生点**（策划 12.2：优先存安全出生点 ID）。
4. **站稳平台摩擦**：玩家站定依赖地面摩擦，树枝缓坡/砖台请挂 `PhysicsMaterial2D`（friction > 0）。
5. **梯子**：`LadderZone` 的 isTrigger 罩住梯子全程；梯顶与平台重叠一小段，方便爬出。
6. **防绕关**（策划 16 风险二）：隔断缺口 > 最大跳距（理论水平 ≈2.25 单位）；储物柜等"不可推、不可跳上"的隔断物画到顶，不给可站顶部。

## 5. 运动包络（策划 6.2，关卡设计红线）

- 移动 3.5 u/s；跳 5.8 u/s；等效重力 18 u/s²。
- 理论跳高 ≈0.93 u；同高度水平 ≈2.25 u。
- **必经**水平跳跃 ≤1.2 u；**必经**向上跳 ≤0.6 u；高处移动靠梯子/树枝坡面。
- 房间宽建议 24—32 u；角色 1.5—1.7 u 高。

## 6. 制作规格（策划 8.6）

- 设计基准 1920×1080；其他宽高比保留关卡完整范围并补边。
- 全项目统一 PPU=100。
- 双年代 Sprite **相同原点与参考坐标**。
- 关键平台边缘与树枝通行面有稳定浅色边缘，不依赖霓虹描边。
- 对白字库覆盖全部中文标点、数字与姓名；发布前验证不缺字。
