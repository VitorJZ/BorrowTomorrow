# 20 AI 出图比例参照系

> 记录《借一点明天》AI 生图时使用的尺度基准与构图规则，供后续出图/返工复用与团队交接。
> 依据 `ArtRegen_2026-10-18/prompts/` 下的实际 prompt 整理（2026-10-18 会话）。

## 1. 为什么需要这套参照系

早期 AI 生成的素材单独看没问题，拼进同一画面后比例失调（人物偏小、建筑过大，旧图门占画高约 60%）。根因：AI 逐张生图时没有「整体」概念，只对单张负责。解决方案是建立一套**以玩家角色为基准的全局比例 + 逐场景百分比坐标**，让 AI 按规则重画，并把可交互元素的位置与游戏碰撞对齐。

## 2. 三层结构

参照系分三层，从通用到具体：

1. **全局「尺子」**（`prompts/common.txt`）——所有生图任务共享的头部，定画风、定尺度、定禁止项。
2. **逐场景「坐标表」**（`prompts/L*.txt`）——每个场景用「距左 % / 距顶 %」钉死每个可交互元素的位置。
3. **L04v3 特化**（`L04v3/prompts/`）——L04 为院子+整栋楼的全景，单独调整基准并给出更精确的坐标。

## 3. 全局比例表（`prompts/common.txt`）

以成年女性 hero（暗红针织外套、深色长裤）为 1 个单位：

| 元素 | 比例 |
| --- | --- |
| 玩家角色身高 | ≈ 画高的 13%（基准尺） |
| 普通房门高 | ≈ 人物身高 1.35 倍 ≈ 画高 18% |
| 窗户高 | ≈ 画高 9–11% |
| 一层墙高（地面→屋檐） | ≈ 画高 22–26% |
| 画幅 | 16:9（如 1672×941） |

L04v3 版本（`L04v3/prompts/common.txt`）将基准改为「身高 = 画高 8.8%」，因该场景取景更广；**门 = 1.35 × 角色** 这条相对规则保持不变。

## 4. 构图铁律

- 正侧视（正交感）横版：建筑立面正对镜头、地面水平一条线、无强透视、无纵深通道。
- 自然写实比例（不要卡通夸张、不要扭曲变形）。
- 画风：手绘水彩拼贴、纸张肌理、柔和轮廓，与 `refs/style_*.png` 参考一致。

## 5. 禁止清单（生图时不得出现）

人物、动物、文字、标牌字样、水印、边框；可攀爬的梯子、台阶、桥板、可站立的平台、通往纵深的路、额外可进入的门洞。

> 这些通行元素由游戏另行放置，背景只画「不可通行的立面」，避免「看得见却走不通」或碰撞错位。

## 6. 逐场景坐标示例

`prompts/L00_1994.txt`：

- 地面线在距顶 **82%**；其下为青石板巷道正面。
- 院门在水平 66%–74%、门高约画高 **18%**。
- 墙面 15%–35% 区间留空（游戏放木栅栏和通知纸）。

`L04v3/prompts/BG_1994.txt`（精度示例）：

- 窗台线脚顶面距顶 68%；腰檐顶面 53.7%；左上墀头顶面 39.4%。
- 暗格盖板中心 81.6% / 33%、宽 4% / 高 5.5%。
- 明确标注「这些位置之后要和游戏碰撞对齐」。

## 7. 核心结论

真正不变的轴心是**相对规则：门 = 1.35 × 角色身高**；「角色占画高 X%」这类绝对数随场景取景变化（13% → 8.8%），不是全局常量。复用本参照系时，优先锁定相对比例，再按场景定取景。
