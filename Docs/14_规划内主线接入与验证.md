## 修复的实现问题

- **启动时序**：Bootstrap 原先在 Awake 调用服务初始化，此时 AudioService 的 AudioSource 尚未创建。无声灰盒未触发错误，接入音乐后复现空引用。本轮移至 Start，先保证各组件 Awake 完成，再按 InitializeOrder 初始化服务。
- **对白链完成判断**：调查物与 NarrativeDirector 按链尾完成标记判断，不因首句无标记而无限重播，也不把中途结束当作揭示完成。
- **回看保存**：完成句子时记入去重 ID 列表，链完成时保存；不把拒播或未读后续条目记成已读。合法整段跳过仍记录该段可回看的文字及必要完成标记。
- **尾声门锁**：Epilogue 原来出口无条件开放，可以不读结局直接离开；现要求 EpilogueSeen。
- **音量**：SFX 不再与 AudioListener 重复乘主音量；配音在每条开始时读取保存的语音音量。
- **字幕可读性**：字幕使用深底浅字，避免叙事插画暗底下沿用灰盒深色文字。

## 修改方式与后续编辑

`Assets/Game/Scripts/EditorTools/StoryContent.json` 是本轮按规划整理的编辑器输入；`StoryContentInstaller` 将它生成到现有 `Data/Dialogue` 资产，并只更新 Bootstrap 的对白库、剧情展示组件、音乐与字幕接线，以及 Epilogue 定义的目标/出口条件。

菜单“BorrowTomorrow → 接入主线内容（保留关卡布局）”不重建关卡，但会覆盖这些主线对白字段。后续修改应同步 JSON，避免重接时回退。完整脚手架已调用同一内容入口；完整脚手架原有的场景重建行为不变，仍不应直接覆盖人工制作场景。

当前工作区只从隔离副本取回经过验证的上述目标资产，没有复制 Library、测试缓存或副本的 Packages。
