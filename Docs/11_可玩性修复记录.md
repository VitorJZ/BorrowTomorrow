## 运行

编辑器打开 `Assets/Game/Scenes/Bootstrap.scene`，进入 Play，再点击开始游戏。

菜单 `BorrowTomorrow → 构建可玩 Windows 灰盒` 可重建八个灰盒场景并构建 Windows 版本。生成器会重建占位场景，正式美术和叙事接入后不要直接重跑覆盖场景。

操作：A/D 移动，空格跳跃，W/S 爬梯，Q/R 或顶部把手调整年代，E 调查和继续，Esc 暂停。

## 验证方式

开发构建可用 `--verify-playable` 启动可选的实机路线检查；正常启动不会自动控制玩家。检查通过真实输入接口驱动同一套 Rigidbody2D、角色控制器、边界、交互物和出口，不使用传送或直接写剧情标记绕过关卡。

覆盖主菜单、L00、L01A/B、L02、L03、L04、尾声和制作名单；检查年代初始化、连续 Q/R 与松键、攀爬时禁止调整、梯顶脱离、脚下支撑保护与暂停。诊断存档放在独立目录。
