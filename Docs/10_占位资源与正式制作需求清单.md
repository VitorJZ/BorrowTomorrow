# 10 占位资源与正式制作需求清单

> 当前工程为**灰盒可玩版**：全部视觉以白方块/斜坡占位，字幕用系统字体，音效库为空，对白为打通流程的最小占位集。
> 本文列出：① 现状占位一览；② 正式美术资源需求（依据策划第 8 章，逐场景逐物体）；③ 音频资源需求（策划 09 章，含代码中已接线的稳定 id）；④ 替换占位的规范。
> 美术由 A/B 组共同配合制作方对接；生产规格以 `06_编码规范.md` 与 `04_场景搭建指南.md` 为准（PPU=100、排序层、双年代同原点）。

## 4. 替换占位的规范

1. **替换在编辑器内进行**（移动/重命名必须由编辑器更新 `.meta`，策划 06 文档）；同原点同参考坐标替换双年代 Sprite，切换不抖动（策划 8.6）。
2. 背景：直接替换/新增 `EraBackground` 层 Sprite 并设 `Visible Inside Mask`；房间 `roomLeft/roomRight` 与遮罩范围已在 `TemporalVisualController` 配好。
3. 年代物体：在 `Temporal_<id>/Past` 与 `/Present` 子物体上替换 SpriteRenderer（保持 collider 或同步调整灰盒碰撞——**树枝等通行物改形必须重新验证防绕关**，策划 16 风险二）。
4. 主角：`Player_Graybox.prefab` 的 `Visual` 子物体换 Animator 版角色；预制体保持 Rigidbody/Capsule/Motor/Interactor 组件与层不变。
5. 对白：直接改写 `Data/Dialogue/` 资产（`nextId` 串联、`setFlags` 勿动——出口与通关依赖这些标记）；配音拖入 `voiceClip`。
6. UI：替换 `UICanvas` 子树视觉；组件与字段名不变（`06_编码规范`），灰盒 `UI.Text` 可换 TMP（B 组统一）。
