# 碰墙悬停与边界操作修正（2026-10-18）

## 碰墙悬停

角色原先没有独立的PhysicsMaterial2D，持续水平顶墙时，接触摩擦可能抵消重力，令角色停在空中并保持顶点动画。

新增PlayerSlide物理材质，摩擦和弹性均为0，绑定到Player_Graybox的Rigidbody2D与CapsuleCollider2D。PlayerMotor2D.Awake也为未配置或带摩擦的碰撞体提供零摩擦回退，保证重新生成角色后仍生效。

地面静止和坡面贴合继续由已有运动逻辑控制，未更改跳跃初速度、重力、移动速度或24帧跳跃资产。

## 边界操作

当前Bootstrap实际键位：Q向左、R向右；E用于调查与对白推进。

原覆盖检查使用整个年代状态的合并包围盒，会将树枝之间、阶梯之间的空隙也算作实体。改为逐个目标碰撞体检查：当前69个场景碰撞体全部为BoxCollider2D，按变换后的盒形与角色包围盒进行分离轴判断，支持旋转与缩放，且不临时激活目标障碍。对角色包围盒留出1厘米接触容差，区分脚底接触与身体被实体覆盖。

脚下支撑撤除仍通过原安全规则拦截。受阻时分别说明：新障碍挡住角色、脚下平台将消失、尚未落地、仍在梯子上、演出/交互未结束，或已到边界最左/最右端；重复提示节流为0.8秒。

长房间中边界可能位于镜头外，把手被夹在屏幕边缘。键盘朝可见区域移动这段边界时速度提高到原来的3倍，进入画面后恢复正常速度；所有阈值仍逐个执行安全检查。
