# 坡面行走修正

## 原因

PlayerMotor2D 原先在世界坐标向上速度超过0.2时直接跳过地面探测。3.5单位/秒走约4度缓坡，正常向上分量就约0.24，因此持续上坡会被误认为离地。CharacterArtAnimator 又额外要求向上速度不大于0.2才认定支撑，进一步使腾空动画无法及时结束。

## 修改

- 用胶囊碰撞体的真实接触法线和向下形状投射寻找可站立表面；忽略触发器、自身、侧墙、过陡面及单向平台下方。
- GroundNormal记录实际坡面法线，地面行走沿坡面切线运动。
- 站稳时关闭重力并设置零速度；下坡和小接缝允许最多0.12单位的短距贴地，空中落地探测限制更小。
- 实际起跳明确清除IsGrounded并恢复重力，离开表面的判定使用相对支撑面的速度方向，避免把普通上坡当成起跳。
- 动画直接信任运动控制器的支撑状态，不再用世界Y速度重复否定它。
- 保留已确认的完整人物行走、跳跃、爬梯素材。
