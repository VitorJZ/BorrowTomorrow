# 03 模块开发指南

> 按"我想做某件事"组织；每节给出涉及文件、步骤与约定。
> 通用规则：**跨模块只通过 Core 接口协作**；新增数据一律走 ScriptableObject（策划 10.5）。

## A. 新增一个年代物体（年代机关）

涉及：`TemporalObjectDefinition`（数据）+ `TemporalObject`（场景）。

1. 在 `Assets/Game/Data/TemporalObjects/` 右键 **Create → BorrowTomorrow → Temporal Object Definition**，填写：
   - `objectId`：稳定 ID（存档引用，**发布后勿改名**）；
   - `anchorX`：年代判定锚点（策划第 7 章灰盒坐标）；
   - `safetyPolicy`：`FullCheck`（通行物）/ `Ignore`（纯装饰）；
   - `anchorHysteresis`：默认 0.05；
   - `pastState / presentState`：状态 ID、Sprite、`canStand`、`blocksMovement`（策划 13.3 交接契约）；
   - `switchSfxId`：切换音效 id（先在 `SfxLibrary` 登记）。
2. 场景中创建物体（layer = `Temporal`），挂 `TemporalObject`，把 Definition 拖入 `definition` 字段。
3. 在物体下创建两个子物体 `Past` / `Present`：
   - 各挂 `SpriteRenderer`（排序层 `EraPlatform`）与该年代的 `Collider2D`；
   - **两套子物体使用相同原点与参考坐标**，防止切换抖动（策划 8.6）；
   - 碰撞形状精简：避免按树叶描边生成高点数 Collider（策划 11.3），长树/长桥允许在子物体下放多个简化 Collider。
4. 把两个子物体分别拖入 `TemporalObject` 的 `pastRoot / presentRoot`。
5. 验证：拖动边界越过锚点，物体应**整体**切换；玩家站上去后反向切换应被阻止并提示"先到稳固的地方。"。

防绕关提醒（策划 16 风险二）：先锁定角色运动包络（6.2 参数），再灰盒测缺口、高度与障碍，最后才画成品。

## B. 新增/修改一段对白

涉及：`DialogueEntry`（数据）+ `DialogueLibrary`（系统根）。

1. `Assets/Game/Data/Dialogue/` 右键 **Create → BorrowTomorrow → Dialogue Entry**：
   - `entryId`：稳定 ID；`nextId` 串联下一条（为空即结束）；
   - `speakerLabel`：如"童年林晓""年轻外婆""主角"；**禁止标注主角真名**（策划 3.2）；
   - `subtitle`：字幕文本；`voiceClip`：配音（可空，无配音降级版仍须讲清剧情）；
   - `requiredFlags`：前置标记；`setFlags`：完成或合法跳过后写入的标记；
   - `holdForConfirm`：文字停留由玩家按 E 确认（策划 5.5）。
2. 把资产加入系统根 `DialogueLibrary.entries`（策划 10.5：对白集中维护，禁止脚本硬编码剧情文本）。
3. 触发方式三选一：
   - 环境回声：场景放 `StoryTriggerVolume`（`once` + `dialogueEntryId`）；
   - 调查：场景放 `NarrativeInteractable`（`entry` + `priority`）；
   - 剧情/演出：程序调用 `NarrativeDirector.PlayStory(entryId, DialoguePriority.Story/Reveal, onCompleted)`。

优先级规则（策划 12.1）：`Ambient < Objective < Story < Reveal`；正在播放的句子不被环境触发器截断；`Reveal` 不可被任何低优先级打断。

## C. 新增一个房间/关卡

1. 复制现有关卡场景（或运行 **BorrowTomorrow → 一键搭建项目骨架** 重建）。
2. 场景结构约定（对照 `Docs/04_场景搭建指南.md`）：
   - `RoomRoot_<id>`：`LevelRoot` + `TemporalObjectRegistry` + `BoundaryController` + `LevelDirector` + `HintDirector`；
   - `TemporalVisual`：`TemporalVisualController` + `PastMask` / `PresentMask`；
   - `Content`：地面（layer `Ground`）、`Spawn_*`、`CheckpointMarker`、`KillZone`、年代物体、出口。
3. 创建/修改 `LevelDefinition` 资产（`Data/Levels/`）：
   - `levelId`（顺序）、`sceneName`、`displayName`、`initialObjective`；
   - `boundaryMin/Max`、`initialBoundary`（L01 双房间场景中由 `LevelRoot.overrideBoundaryRange` 覆盖）；
   - `spawnId`、`exitRequiredFlags`、`exitLockedHint`、`hintGroups`（三级提示，`stageKey` 绑定完成标记）。
4. 把 Definition 加入 `GameSession.levelCatalog`（决定"下一关"推进顺序）。
5. 场景加入 Build 列表（EditorBuildSettings；脚手架会自动维护）。

同场景双房间（如 L01 水渠房/树房）：两个 `RoomRoot`，出口门用 `ExitDoor` 的 `SameSceneRoom` 模式指向目标房间与出生点；每房间独立边界范围与初值。

## D. 新增音效/环境声

- **一次性音效**：`SfxLibrary` 登记 `id + clip`；调用 `IAudioService.PlaySfx(id)`（年代物体切换自动经 `switchSfxId` 播放）。
- **环境声按年代启停**（策划 11.4）：把 `EraAmbienceEmitter` 挂在 `TemporalObject` 同物体或子物体，设 `ownerEra`；不属于年代物体的恒定环境声（风、鸟）直接挂常驻 `AudioSource`。
- **音乐**：`AudioService` 的 `musicPast / musicPresent / musicEpilogue` 三槽位；年代混合比例由 `SetEraMix(pastAreaRatio)` 驱动（策划 09）。

## E. 调整玩家运动参数

`PlayerMotor2D` Inspector（策划 6.2 原型值）：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| moveSpeed | 3.5 | 水平速度（单位/秒） |
| jumpVelocity | 5.8 | 起跳速度（理论跳高 ≈0.93） |
| fallAcceleration | 18 | 等效重力（换算 gravityScale） |
| coyoteTime | 0.1 | 离地宽容 |
| jumpBufferTime | 0.12 | 跳跃预输入 |

修改后必须重新灰盒验证关卡隔断（策划 6.2：重要隔断必须超过跳跃能力）。

## F. 新增输入动作

1. `InputBindings` 增加键位数组；
2. `IInputSource` 增加属性/方法（`Core/Interfaces/InputInterfaces.cs`）；
3. `InputRouter` 实现采样；
4. 消费方（UI/玩法）通过 `ServiceRegistry.Get<IInputSource>()` 读取，**不得**直接 `Input.GetKey`（策划 10.1）。
5. 屏幕提示文案从同一输入映射读取（策划 5.2）；如需重绑，后续把 `InputBindings` 序列化为设置项。

## G. 扩展存档字段

1. `SaveData`（`Core/Data/SaveData.cs`）加字段并升 `CurrentSaveVersion`；
2. `SaveService.Migrate` 补充版本迁移分支；
3. 写入方：`CheckpointService.WriteTo` / `GameSession.SaveProgressNow`；读取方：`RestoreFrom` / `RestoreLatest`。
4. 跑 `SaveServiceTests` 确认往返与备份路径（策划 15.5）。

## H. 跑测试

`Window → General → Test Runner → EditMode → Run All`。现有 5 组测试：阈值计划、安全阻挡、存档往返/备份、标记幂等、状态机暂停恢复。

边界与碰撞逻辑改动必须重新验证受影响关卡（策划 15.5）；美术小改不强制扩写测试。
