# 06 编码规范

> 以下为开发约定；是否符合需检查具体改动，不能据文档宣称现有代码全部达标。

## 1. 通用

- 引擎版本 **1.10.4**；不要引入模板之外的包，新增包需全员确认并记录 `Packages/manifest.json`。
- 每个模块目录一个 asmdef；**不得给已有 asmdef 随意添加引用**——跨模块协作只走 `Core/Interfaces` 接口（装配层的向下依赖见 02 文档依赖图）。
- 一个类一个文件，文件名 = 类名。
- 显式访问修饰符；字段优先 `[SerializeField] private`，避免 public 字段。

## 2. 命名

| 对象 | 约定 | 示例 |
| --- | --- | --- |
| 类/方法/属性 | PascalCase | `BoundaryController`、`ApplyEra` |
| 私有字段 | camelCase，序列化字段可带 `_` 前缀按现状保持 | `committedB`、`playerPrefab` |
| 常量 | PascalCase | `StoryFlags.IntroPlayed` |
| 接口 | `I` 前缀 | `IBoundaryContext` |
| 枚举值 | PascalCase | `Era.Past`、`SafetyBlockReason.SupportRemoved` |
| 稳定 ID（objectId/entryId/levelId/spawnId/checkpointId） | 沿用既有 ID 大小写（如 `L01A`、`L00_fence_gate`），新后缀推荐小写下划线；**发布后不随意改名** | `old_ladder`、`intro_tape_01` |
| 事件 | `On` 前缀 + 过去式 | `OnBoundaryCommitted` |
| 测试类/方法 | `被测类Tests` / `场景_断言` | `SaveServiceTests.SaveAndLoad_RoundtripPreservesData` |

## 3. 注释

- 注释写**为什么**（并标注策划依据章节），不写"这行做了什么"。
- 公共 API 与核心算法用 `/// <summary>`；策划条目引用格式：`（策划 4.5）`。
- 不写与代码无关的备注、待办清单入代码——用 issue。

## 4. 数据驱动约定（策划 10.5）

- **静态设计数据** = ScriptableObject（`LevelDefinition` / `TemporalObjectDefinition` / `DialogueEntry`）。
- **运行状态** = 普通 `[Serializable]` 结构（`SaveData` 等），不用场景对象引用保存状态。
- 剧情触发与保存使用**稳定字符串 ID**，禁止使用 `GameObject` 实例 ID 或 `GetInstanceID()`。
- 字幕与对白集中在 `DialogueEntry` 资产，**禁止**在脚本里硬编码剧情文本。

## 5. 引擎使用规则

- 移动只经 `Rigidbody2D`，禁止对同一角色混用 `Transform` 位移与刚体位移（策划 11.3）。
- 物理操作在 `FixedUpdate`；帧级输入采样在 `Update`（`PlayerMotor2D` 的 buffer 模式）。
- 不做每帧 `Find*`/全场景查找；初始化期一次或经 `ServiceRegistry`（策划 10.3）。
- 服务组件在 `Awake/OnBootInitialize` 注册、`OnDestroy` 注销；重开关卡不得重复创建。
- 事件订阅必须成对退订（`OnEnable/OnDisable` 或 `Awake/OnDestroy`）。
- 协程里操作 UI/服务前判空容错。

## 6. 渲染约定

- 所有 Sprite 指定排序层（见 04 文档表格）；机关与角色不使用视差。
- 双年代 Sprite 相同原点与参考坐标；PPU=100。
- 碰撞形状精简（策划 11.3），复杂树叶不做逐点描边 Collider。

## 7. 测试约定

- 核心可测面（策划 15.5）：边界阈值排序、安全阻挡、存档序列化、标记幂等——改动这些模块必须保持测试全绿。
- 新的边界/碰撞逻辑改动需重新人工验证受影响关卡。
- 纯逻辑测试放 `Assets/Game/Tests/` 的 EditMode 程序集；需要物理帧与场景生命周期的测试应使用独立 PlayMode 程序集，现有冒烟测试归类问题见 11。

## 8. 性能红线（策划 11.6）

- 目标：1080p 稳定 60fps（**待实测**，不是已达成结论）。
- 静态配置不在每帧分配集合或反复查找；只在边界变化时计算年代切换。
- 背景大图与透明叠层数量适度控制。
- 开发叠层（B、锚点、碰撞轮廓、检查点、标记）发行版必须关闭。
