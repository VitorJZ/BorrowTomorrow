# 07 里程碑与验收清单

> 摘自策划方案第 14、15 章。团队规模与截止日期明确后，在此补充人日排期。

## 1. 里程碑（按成果验收，策划 14 章）

| 阶段 | 目标 | 退出条件 |
| --- | --- | --- |
| **A 机制灰盒** | 角色移动、轻跳、梯子、边界控制、年代切换、安全阻挡、跌落恢复；**只做 L02 砖台顺序谜题** | 陌生测试者不用口头指挥也能理解"先上砖台再切换" |
| **B 一关完整样板** | L01B 最终风格 + 字幕、背景遮罩、音效、存档、正式构建 | 美术/碰撞/音效/UI 读同一年代状态；发布包可运行 |
| **C 全流程灰盒** | 五关 + 尾声接通，临时图与配音通关 | 剧情因果完整无卡死；首次试玩时长接近 25–35 分钟 |
| **D 内容生产** | 替换美术/配音/镜头，按统一样板制作，不加新能力 | 关键剧情无需可选收集也能理解；双年代美术不误导通行 |
| **E 打磨交付** | 平台验证、存档、暂停、跳过、字幕、音频连续通关验证 | 操作说明、无剧透简介、截图、短演示视频就绪 |

**首要行动（策划交付说明）**：优先完成 L02 灰盒 + 一次 Windows 构建，再扩展内容。

## 2. 功能优先级

- **P0**：完整剧情、边界谜题、五关、恢复、字幕、保存、可执行包。
- **P1**：全部配音、狗动画、更多环境交互、平滑年代音频。
- **P2**：手柄、定制复杂 Shader、额外收藏、更多非必要演出。
- 时间不足先削 P2 与装饰数量，**保留故事揭示与两天后真实交付**。

## 3. 机制验收（策划 15.1）

- [ ] 快速从最左拖到最右，不穿过新生墙体，不删除脚下支撑。
- [ ] 边界停在锚点附近不闪烁（滞回）；鼠标与 Q/R 结果一致。
- [ ] 爬梯、腾空、暂停、剧情期间不会错误进入时间调整。
- [ ] 镜头切换后边界不会跳到鼠标旧位置（拖动时镜头冻结）。
- [ ] 所有可走平台可见形状与碰撞吻合。
- [ ] 整棵树按树干锚点切换，末关没有局部成年枝条的绕解。

（自动化覆盖：`BoundaryChangePlanTests`、`TemporalSafetyResolverTests`、`GameStateMachineTests`）

## 4. 关卡验收（策划 15.2）

- [ ] 五关标准解均可重复完成。
- [ ] 以最大跳距测试捷径，必经谜题不能被普通跳跃绕过。
- [ ] 安全砖台/门槛尺寸足够站稳，附近无装饰碰撞推挤。
- [ ] 每个跌落点恢复后可继续，不存在恢复到缺失平台或关闭出口的问题。
- [ ] 本关重置不重复强制观看已完成的长演出。

## 5. 剧情验收（策划 15.3）

- [ ] 首次游玩者能说清：玩家是谁、童声来自哪里、铁盒怎样回到现实。
- [ ] 不阅读任何可选账本也能理解结局。
- [ ] 年龄 47→77、7→37，称呼始终一致。
- [ ] 开场没有把主角标成林晓，没有称外婆为已故。
- [ ] 结尾明确"两天后"，林晓带回真实盒子。
- [ ] 被面花纹在前文至少出现两次，结尾可辨认。

## 6. 技术验收（策划 15.4）

- [ ] 目标平台离线全流程通关。
- [ ] 正常退出再继续，恢复正确检查点与剧情进度。
- [ ] 字幕、中文字体、音量设置在发布包有效。
- [ ] 跳过演出不漏写任务标记；暂停不导致音频和字幕错位。
- [ ] 无开发调试层、测试快捷键、缺失资源与阻断性控制台错误。
- [ ] 记录基准机器配置与性能实测（不能只写"已优化"）。

## 7. 试玩记录（策划 15.6）

- 邀请不知道剧情的人独立试玩；记录每关耗时、首次卡住点、提示次数、跌落数、错误理解；**卡住时不立即口头教学**。
- 试玩后只问三个核心问题：
  1. 你什么时候觉得自己可能不是林晓？依据是什么？
  2. 你认为现实里的铁盒是怎样被找到的？
  3. 哪一道谜题是在思考，哪一道只是找不清可站的位置？
- 若多数人误解"实物穿越"→ 调整告知位置与两天后演出，而不是加设定说明。
- 太短 → 增加同机制的有意义变体；过长 → 先解决信息与碰撞不清，不缩短结尾。

## 8. 容易遗漏的首版验收（策划 04、05、07、12 章）

以下是总规划已有要求的展开，不将尚未实现自动降为 P1/P2；装饰美术可后补，必要交互必须可用。

- [ ] 鼠标只能从顶部把手开始调整；Q/R 与其共用安全路径；调整中角色站定、重力照常、镜头固定。
- [ ] Backspace 先显示可读的确认/取消界面；连续两次跌落只提供可关闭提示，不自动改谜题。
- [ ] H 按阻塞阶段逐级给提示，阶段完成停止旧计时；未按 H 不自动报答案。
- [ ] Tab 回看目标和已听录音文字；字幕默认开启、字号可调、文本可确认、配音可跳过。
- [ ] 设置可重绑关键输入，屏幕提示读取相同映射；重开游戏保留字幕和音量设置。
- [ ] 暂停停止操作、剧情计时和对白推进；恢复正确来源状态，空中/拖动释放/转场场景均不出错。
- [ ] L01A/B 独立边界与快照；冷启动继续能创建玩家并恢复正确房间，刚换关跌落不套用旧关快照。
- [ ] 系统拒播/打断不写未读剧情完成标记；合法跳过完整揭示仍更新身份、目标与出口条件。
- [ ] 关键剧情完成后立即保存；跌落恢复空间不回滚故事阅读进度，也不恢复过时目标。
- [ ] L00 开门后永久通行；所有出口 E 确认，必要调查未完成时给出明确提示。
- [ ] 章节选择只在通关后开放；末关可退回窗台看过去，无全图比例门锁。
- [ ] 年代可通过年份、材质、形状区分；音频线索有文字/视觉对应，震动可关闭；非 16:9 不裁掉机关。

节奏参考：L00 3 分钟、L01 5 分钟、L02 6 分钟、L03 7 分钟、L04 6 分钟、尾声 3 分钟；均为试玩目标，不是当前实测时长。重点是完整脚本与解谜节奏，不能用强制等待补足时长。
