# 01 项目概述与设计支柱

> 依据《借一点明天 2D 团结引擎游戏策划方案 v1.0》第 01、02、04 章整理。
> 本文档是团队共识基线；与策划原文冲突时以策划原文为准。

## 1. 游戏定位

- **类型**：单人、2D 横版、关卡制、环境解谜、轻平台移动、亲情叙事。
- **主题**：边界之间——记忆与现实、过去与现在、被照顾与照顾别人。
- **目标平台**：优先 Windows 桌面可执行版本。
- **目标时长**：初见约 25—35 分钟，以 30 分钟作为关卡节奏目标。
- **失败方式**：跌落后回到最近安全点；无生命数、无战斗、无限时追逐。

## 2. 一句话玩法与故事

- **玩法**：拖动一条竖直时间边界，让左侧成为 1994 年、右侧成为 2024 年，借两个年代的道路抵达阁楼。
- **故事**（内部概念，含剧透，禁止用于公开简介）：一个以为自己在寻找外婆遗物的人，最终发现自己就是外婆，而现实中的孙女还在等她说完那句话。
- **面向玩家的无剧透简介**：老院即将腾空，你回来寻找一个蓝色铁盒。拖动过去与现在的分界线，借一段旧楼梯，也借一棵长大的树。有些路只有过去存在，有些东西要到后来才能看见。

## 3. 核心玩法规则（策划 04 章）

### 3.1 边界定义

- 每个房间有固定的世界坐标范围，边界 B 是房间中的一条竖直线。
- 物体锚点 `x < B`：**过去（1994）**；`x > B`：**现在（2024）**。
- 边界右移 → 过去覆盖更多；边界左移 → 现在覆盖更多。
- 允许移到房间范围稍外侧，形成全过去或全现在。
- **跨房间不共享边界数值**；每间房保存自己的边界位置（`RoomBoundarySnapshot`）。

### 3.2 物体四分类

| 分类 | 说明 | 实现 |
| --- | --- | --- |
| 恒定物体 | 两年代形状与碰撞不变（砖台、门槛、主梁） | 普通 GameObject，不挂 `TemporalObject` |
| 年代物体 | 有过去/现在两套预设状态（木板、梯子、树枝、储物柜） | `TemporalObject` 组件 |
| 叙事物体 | 调查后播放文字或声音（校服、照片） | `NarrativeInteractable`（可同时是年代物体） |
| 装饰物体 | 仅视觉变化，不参与通行 | 可用背景连续遮罩；独立整件装饰可挂 `TemporalObject` 且 `SafetyPolicy.Ignore`，不得承担通行碰撞 |

### 3.3 切换规则

- 关键年代物体以**锚点为准整体切换**（锚点用物件底座小标记提示）。
- 长桥、长树枝也整体切换，不做"可见一半却有整块碰撞"。
- 锚点处存在小范围**滞回**（`anchorHysteresis`，默认 0.05），防反复切换。
- 每关可行状态的边界区间建议不小于 1 个世界单位。

### 3.4 安全规则（统一规则，非某关临时限制）

- 玩家站在某年代平台上时，**不允许把该平台切换成无支撑状态**。
- 新实体将覆盖玩家身体时，**不允许切换**。
- 此时边界停在切换阈值之前，标记闪烁，提示："先到稳固的地方。"
- 拖动只能在落地或站稳时开始；爬梯和腾空时不能开始。
- 拖动期间角色站定，水平移动和跳跃暂停，重力与世界时钟照常；释放后立即恢复。

### 3.5 恢复规则

- 跌落淡出约 0.3 秒 → 回到最近检查点 → 恢复对应边界与机关快照。
- 已读剧情标记保留，不重复播放；空间状态按检查点重置。
- `Backspace` 显示恢复确认，再次确认恢复本关最近检查点。

## 4. 三个制作优先级

1. 玩家始终看得懂哪块地面能站、哪个物体变了。
2. 每一道谜题都增加对同一条规则的理解，不靠不断增加能力维持新鲜感。
3. 反转发生后，玩家能重新解释先前听到的话和做过的动作。

## 5. 明确不做（范围控制）

自由改写历史、年龄变身、物品跨时代搬运、战斗、追逐、复杂水体、动态冰冻、自由 AI 对话、多结局分支。
另不做记忆图钉；Codely 仅作开发辅助，不进入运行时剧情。
这些不是本版预留系统；只有核心版本完整后才重新讨论是否扩展。

## 6. 世界观速查

- **地点**：虚构中国南方小城，两层砖木民居合院（院门、水渠、桂花树、缝纫间、外廊、阁楼）。
- **人物**：外婆（1947 年生；1994 年 47 岁、2024 年 77 岁）；林晓（1987 年生；1994 年 7 岁、2024 年 37 岁）；林晓母亲（仅照片题字）；阿黄（1994 年的狗）。
- **玩家身份**：从始至终操作的是**外婆在记忆空间中的自我形象**。系统不写"你就是林晓"，任务不写"外婆已经去世"，没有假日记等直接欺骗文本。
- **记忆空间性质**：叙事表现，不是可物理穿越的时空，也不是认知障碍的医学模拟。现实交付必须通过"说出位置—孙女取回"完成。

## 7. 叙事红线（摘自策划 03、15.3 章）

- 开场 40 秒禁止显示主角姓名、病房、诊断书或外婆死亡信息。
- 关键标记 `PhotoRevealed` / `IdentityKnown` 只在揭示演出完成或合法跳过后写入。
- 身份揭示后不再用身份迷惑作为悬念。
- 结局不暗示完全康复，不暗示林晓靠取回盒子拯救或结束了外婆生命。
- 展示视频避免公开展示结尾身份反转。
