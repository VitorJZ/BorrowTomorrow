# 已确认的走路与跳跃动画接入

## 使用的资产

- 行走：`Assets/Game/Art/Characters/WalkCandidate_v3`，用户认可的8帧、10fps循环。
- 跳跃：`Assets/Game/Art/Characters/JumpRecovery_v5`，上一版12张完整人物关键帧，加上落地后半起身、微屈膝两帧，共14帧。没有采用被否决的24帧方案，也没有拆分人物身体。
- 保留当前已接入的 ClimbFrames_v5 15帧爬梯配置。

## 游戏驱动

`Player_Graybox.prefab` 的 CharacterArtAnimator 保存原生AnimationClip引用、完整人物Sprite序列和每帧时长。运行时由同一个组件写入SpriteRenderer，避免多个动画组件相互覆盖。

跳跃分为五段，共覆盖全部14张图：

| 游戏段 | 完整人物帧 | 触发方式 |
| --- | --- | --- |
| JumpPrepare | 原第1—3帧 | 地面按跳跃后，80ms短蓄力 |
| JumpRise | 原第4—6帧 | 实际施加原起跳速度后，随上升速度推进 |
| JumpApex | 原第7帧 | 垂直速度接近0 |
| JumpFall | 原第8—9帧 | 下落速度推进 |
| JumpRecover | 原第10—11帧、两张新增帧、原第12帧 | 实际落地后播放恢复动作 |

落地站定时完整播放恢复段；继续水平移动时可切换回行走。再次起跳、爬梯及检查点恢复会清理过期跳跃状态。
地面跳跃加入80ms蓄力以播放准备动作，起跳速度、重力、原有跳跃高度保持原参数；离地宽容跳跃与跳离梯子不增加这段等待。
